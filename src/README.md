项目名称：多智能体医学健康档案 RAG-Agent 系统

项目背景
传统健康问答系统往往只依赖大模型通用知识，容易出现回答缺乏个人健康档案依据、医学建议不够谨慎、无法调用专业计算工具等问题。本项目面向“个人健康档案问答”场景，构建了一个基于 LangGraph 的多智能体协作系统，使大模型能够结合私有健康档案检索结果、医学计算工具和安全审核流程，生成更有依据的健康分析报告。

项目目标
项目目标是实现一个可通过 API 调用的健康档案智能问答服务：用户提出健康问题后，系统能够自动判断是否需要检索健康档案、是否需要调用医学工具，并在生成回答后进行安全审核，最终返回结构化健康建议，同时可将报告保存为 PDF 文件，方便用户留档查看。

项目描述
该项目采用 FastAPI 提供 /agentvqa 服务接口，兼容 OpenAI Chat Completions 风格的请求和响应格式，支持普通输出和 SSE 流式输出。核心工作流由 LangGraph 编排，包含多个职责明确的智能体节点：
Supervisor Agent：判断用户问题类型，决定是否进入健康档案检索、医学工具调用或直接生成报告。
Retrieval Agent：从本地 ChromaDB 私有健康档案库中检索相关内容。
Medical Tool Agent：根据问题自动调用 BMI 计算、血压均值计算、血压参考分层等医学工具。
Report Agent：结合用户问题、检索结果和工具结果生成健康分析报告。
Review Agent：对报告进行医学安全审核，检查是否存在过度诊断、证据不足或不谨慎建议。
Revise Report Agent：当审核不通过时，根据审核意见自动修订报告。
PDF Agent：将最终健康报告保存为本地 PDF。
Memory / Prepare Agent：维护多轮对话历史，并在上下文过长时进行摘要压缩。
在 RAG 检索层，项目不仅使用 ChromaDB 向量检索，还实现了 BM25 关键词检索与向量检索的 hybrid fusion，提高中文健康档案场景下的召回稳定性。系统支持智谱 GLM API，也预留了 Ollama 本地模型接入能力。

技术栈
Python、FastAPI、Uvicorn、LangGraph、LangChain、ChromaDB、BM25、FPDF。

项目结果
项目实现了一个端到端的多智能体健康问答原型：用户输入健康问题后，系统可以自动完成任务路由、档案检索、医学指标计算、报告生成、安全审核、报告修订和 PDF 保存。相比单轮大模型问答，该系统具备更清晰的流程可控性、更强的可解释性和更好的工程扩展性，适合继续扩展到更多医学工具、人工审核、检索质量评估和长期健康档案管理场景。

















功能：
1.根据医生询问的健康问题，从私有健康档案库(RAG)中检索相关内容
2.根据检索的内容和问题进行健康分析并最终调用外部工具把生成的报告以PDF文件保存到本地

检索增强方向：Rerank / Hybrid Search
Query Rewrite 方向：问题改写
检索质量判断方向：Retrieval Grading
多轮记忆方向：Conversation Memory
流式输出方向：真正的 Streaming
配置管理方向：环境变量和配置文件
工具调用方向：多工具 Agent
人工审核方向：Human-in-the-loop
评估方向：RAG Evaluation
